## Reassessment leads

These are documented tensions to investigate, not a replacement implementation plan:

- The ledger acknowledges limited manual permit reconciliation in the city's existing method; the original agent file says there is none.
- The old agreement requires a model frozen across both epochs, while the implementation failure table suggests fine-tuning for poorer 2025 predictions. The co-registration diagram also needs reconciliation with the prose about alignment before inference.
- The ledger includes unincorporated DeKalb, while the implementation primarily describes Atlanta's permit system and NPU evaluation. Geographic coverage needs corresponding jurisdiction-specific records and evaluation units.
- Source availability and readiness assertions need current sample retrieval, coverage checks, provenance, and a recoverable storage path. References and prior verification dates are starting evidence rather than confirmation of present access or completeness.
- Architecture choices, epoch suitability, numerical targets, resource estimates, schedules, and validation assumptions need justification in the replacement plan.
